# Prompt Patterns

- Response length/format preferences: terse. No trailing summaries or
  restating what was just done — short status updates during work, one
  or two sentences of "what changed / what's next" at the end, nothing more.
- When to ask before acting vs. just doing it: for non-trivial code changes,
  state the plan first and wait for confirmation before editing — this
  applies even to small/safe changes, not just risky/irreversible ones
  (migrations, data deletion, etc. obviously still require explicit
  confirmation too).
